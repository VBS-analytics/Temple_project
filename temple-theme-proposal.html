02 — Why the Blue Doesn't Feel Like a Temple

🔵

Blue is Corporate, Not Sacred

Blue (#1565C0) signals trust and technology — banks, SaaS, dashboards. A temple portal should feel warm, devotional, and grounded in tradition, not modern enterprise software.

🌡️

Cold Backgrounds

The current page background (#FFFFFF) and section background (#F0F4FF — blue-tinted) feel sterile. Temple spaces are warm — sandalwood, oil lamps, flower garlands, terracotta.

🏛️

Label Color is Too Digital

Label color #1565C0 (blue) is used for uppercase field labels across all pages. A warm dark brown or sandalwood would feel much more appropriate for a spiritual context.

✨

Gold is Underused

Gold (#C9A227) and brass tones are central to temple aesthetics — vilakku lamps, deity ornaments, gopuram decorations. The current theme uses only #F5C518 (turmeric yellow) sparingly.

05 — Files to Change (Implementation Plan)

  • frontend/src/styles/index.css — Update all 18 CSS variables in :root. Change nav colors, backgrounds, borders, label colors, shadows. This single file drives most of the theme.
  • frontend/tailwind.config.ts — Update temple.navTop, temple.navMenu, temple.tab, temple.pageBg, temple.sectionBg, temple.border, temple.heading values. Keep temple.adminNavTop and temple.adminNavMenu as blue.
  • frontend/src/components/AppLayout.tsx — The nav uses hardcoded hex colors in addition to CSS vars. Specifically the bg-[#1565C0], bg-[#1976D2], bg-[#F5C518] inline classes need updating for donor nav only.
  • frontend/src/styles/index.css (label rule) — Line 76: color: #1565c0 on uppercase labels → change to #7B3F00 for donor pages (or use a CSS variable).
Key insight: Because the project already uses CSS custom properties (--temple-nav-top, --temple-page-bg, etc.), most of the change is concentrated in index.css. Updating those 18 variables will instantly restyle all donor pages. Only a few hardcoded hex values in AppLayout.tsx need surgical changes.
